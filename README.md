# A4P 이미지 (a4p-image)

노트에 붙여넣은 이미지를 **볼트 로컬에 백업**하고 **Cloudflare R2에 자동 업로드**한 뒤, 노트에는 **공개 URL**(`![이름](https://…)`)을 삽입하는 옵시디언 플러그인입니다.

share-note 등으로 노트를 웹에 공유할 때 로컬 첨부 이미지가 보이지 않는 문제를 해결합니다. 노트 속 링크가 처음부터 공개 URL이므로 어디서 공유해도 이미지가 그대로 보입니다.

## 기능

| 명령 (명령 팔레트) | 설명 |
| --- | --- |
| (자동) 붙여넣기·드롭 | 이미지를 붙여넣거나 드롭하면 압축·EXIF 제거 → 로컬 백업 + R2 업로드 후 URL 삽입 |
| 이미지 갤러리 열기 | 사이드바 썸네일 갤러리 — 검색, 상태·날짜 필터, 노트별(실사용처 기준) 그룹, 용량 통계. 카드 클릭 시 큰 미리보기 모달(삽입·URL 복사·노트 열기·브라우저 열기·사용처 검색) |
| 실패한 업로드 재시도 | 오프라인 등으로 실패한 업로드를 다시 시도하고 로컬 임베드를 URL로 치환 |
| 현재 노트의 로컬 이미지 → 클라우드 변환 | 미리보기(dry-run) 승인 후 기존 `![[이미지]]`를 URL로 일괄 변환 (크기 지정 `\|300` 보존) |
| 볼트 전체의 로컬 이미지 → 클라우드 변환 | 위와 동일, 볼트 전체 범위 |
| 이미지 주소 일괄 변경 | 옛 base URL → 새 base URL 일괄 치환 (커스텀 도메인 전환·잘못 입력한 주소 복구). 스캔(dry-run) 후 실행 |
| 미사용 이미지 리포트 생성 | 어떤 노트도 참조하지 않는 이미지를 분류한 리포트 노트 생성 (파일은 건드리지 않음) |
| 미사용 이미지 휴지통 이동 | 체크박스 선택 + 최종 확인 후에만 볼트 `.trash/`로 이동 (영구 삭제 없음) |
| Eagle에서 이미지 검색·삽입 | Eagle 라이브러리를 검색해 선택한 이미지를 업로드 파이프라인에 태워 삽입 (데스크톱 전용) |

### 파일명·최적화

- **파일명 규칙**: 기본은 노트 제목 기반 — `옵시디언` 노트에 붙여넣으면 `옵시디언_1.webp`, `옵시디언_2.webp` … 로컬 파일명과 R2 키가 동일합니다. 타임스탬프 방식으로 변경 가능. 드롭한 파일은 원본 이름을 유지합니다.
- **업로드 전 최적화** (기본 켬): 최대 폭 1920px 리사이즈 + WebP 변환(보통 용량 70~90% 절감) + EXIF(GPS·기기 정보) 자동 제거. svg/gif 제외, 일괄 변환(기존 파일)에는 적용되지 않습니다.

### 동작 원칙

- **로컬 저장이 항상 먼저** — 업로드가 실패해도 이미지는 유실되지 않고 `![[로컬]]`로 폴백됩니다.
- **같은 이미지는 한 번만 업로드** — 내용 해시(SHA-256)로 중복을 감지해 기존 URL을 재사용합니다.
- **텍스트+이미지 혼합 클립보드는 건드리지 않음** — Word 등에서 복사한 내용은 옵시디언 기본 동작에 양보합니다.
- **삭제 기능 없음** — 미사용 정리도 리포트와 `.trash/` 이동(사용자 승인 필수)까지만. R2 객체는 절대 삭제하지 않습니다.
- 로컬 백업↔클라우드 URL 매핑은 플러그인 폴더의 `index.json`에 기록되어 갤러리·미사용 판정·재시도가 이를 기반으로 동작합니다. 노트에서 URL이 사용 중인 백업 파일은 미사용으로 판정되지 않습니다.

## Cloudflare R2 최초 설정 (1회)

1. [Cloudflare 대시보드](https://dash.cloudflare.com) → **R2 Object Storage** → 버킷 생성 (예: `obsidian-images`). 무료 계층: 저장 10GB/월, 이그레스(전송료) 무료.
2. 버킷 → **Settings → Public access**:
   - 간편: **r2.dev subdomain** 활성화 → `https://pub-xxxx.r2.dev` 형태의 URL 확보
   - 장기 권장: **Custom domain** 연결 (예: `img.example.com`) — r2.dev는 속도 제한이 있음
3. R2 개요 → **Manage R2 API Tokens** → **Create API Token**:
   - 권한: **Object Read & Write**
   - Bucket 스코프: 위에서 만든 버킷만
   - 생성 후 표시되는 **Access Key ID / Secret Access Key** 복사 (한 번만 보임)
4. 대시보드에서 **Account ID** 복사 (R2 개요 우측 또는 URL에 표시)
5. 옵시디언 → 플러그인 설정에 5개 값 입력 → **연결 테스트** 버튼으로 검증 (테스트 객체를 올렸다 지우는 왕복 검사)

## 보안 주의

- R2 Secret은 볼트의 `.obsidian/plugins/a4p-image/data.json`에 저장됩니다. **볼트를 공개 git 저장소에 올리지 마세요.** 올려야 한다면 이 파일을 반드시 제외하세요.
- 업로드된 이미지는 URL을 아는 누구나 볼 수 있는 공개 객체입니다. 민감한 이미지는 붙여넣기 전에 한 번 더 확인하세요 (키에 무작위 접미가 있어 추측은 어렵지만, 공유된 노트를 통해 URL이 퍼질 수 있습니다).

## 다른 플러그인과의 공존

- **share-note**: 노트 속 이미지가 이미 공개 URL이므로 공유 페이지에서 그대로 표시됩니다.
- **obsidian-paste-image-rename**: 이 플러그인이 붙여넣기를 가로채므로 기본 모드에서는 충돌하지 않습니다. rename 플러그인의 "Handle all attachments" 옵션을 켠 경우에도 이름 변경을 자동 추적하지만, 해당 옵션은 끄는 것을 권장합니다.
- 타사 "미사용 첨부 정리" 플러그인은 이 플러그인의 로컬 백업(노트가 참조하지 않는 파일)을 미사용으로 오판할 수 있습니다. 정리는 이 플러그인의 미사용 리포트를 사용하세요.

## 개발

```bash
npm install
npm run dev        # watch 빌드
npm run build      # 타입체크 + production 빌드
npm test           # vitest (서명·이름·매니페스트·변환·미사용 판정)
```

- dev vault: `.obsidian/plugins/a4p-image`에 프로젝트를 심볼릭 링크하고 플러그인 리로드
- 실사용 볼트에는 검증 후 `main.js` + `manifest.json` + `styles.css`를 **복사**해서 설치 (심볼릭 링크 비권장)

## 아키텍처 메모

- R2 업로드는 S3 호환 엔드포인트에 **AWS SigV4 직접 서명** (`src/r2/sigv4.ts`, Web Crypto만 사용 — 외부 인프라·Worker 불필요, 모바일 호환). AWS 공식 문서의 예제 벡터로 테스트 검증.
- 모든 HTTP는 옵시디언 `requestUrl` 사용 (CORS 우회 — 버킷 CORS 설정 불필요).
- Eagle 연동은 로컬 API(`http://localhost:41595`)를 사용하며 Eagle 미실행 시 조용히 비활성화됩니다.
- 참고: [cmds-eagle](https://github.com/johnfkoo951/cmds-eagle) (MIT)의 붙여넣기 게이트·플레이스홀더 패턴을 참고해 처음부터 새로 작성했습니다.
